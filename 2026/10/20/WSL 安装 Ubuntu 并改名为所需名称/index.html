WSL 安装 Ubuntu 并改名为所需名称

文档简介

本文按两条线索完整说明 WSL Ubuntu 子系统：

  • 线索一：从 0 安装到配置设置 —— 启用 WSL → 解压 .appx 安装包 → 初始化建用户 → 把发行版改名为所需名称 → 同步 Windows Terminal 显示名 → 网络环境配置 → 改名后的常用命令。
  • 线索二：完全卸载 —— 注销发行版、清理虚拟磁盘与残留文件、清理注册表、清理终端配置、可选关闭 WSL 功能。

适用环境：Windows 10 2004+ / Windows 11。文中「所需名称」为举例，实际可换成任意你想用的名字（如 Ubuntu-OpenClaw）。

线索一：从 0 安装到配置设置

1. 启用 WSL 前置（首次安装必做）

如果电脑从没装过 WSL，先启用两个系统功能：

  1. 打开「控制面板 → 程序和功能 → 启用或关闭 Windows 功能」；
  2. 勾选 「适用于 Linux 的 Windows 子系统」 和 「虚拟机平台」；
  3. 点击确定，重启电脑。

也可以直接在 PowerShell（管理员）里一键安装：

安装完成后重启，再用 wsl --status 确认 WSL 可用。

说明：离线 .appx 安装包方式不需要联网下载发行版，适合内网/无外网环境，也适合手动指定安装位置（如放到 J: 盘）。

2. 解压 Ubuntu .appx 安装包

3. 初始化发行版（首次启动建用户）

  1. 打开资源管理器，进入解压目录：J:\WSL\Ubuntu-openclaw；
  2. **双击 ubuntu.exe**（或在该目录 PowerShell 里执行 .\ubuntu.exe）；
  3. 等待初始化，按提示设置 用户名 和 密码（Linux 下输入密码不显示字符，属正常现象）；
  4. 出现命令行提示符即说明发行版注册成功。

此时执行 wsl -l -v 应能看到一个名为 Ubuntu 的发行版（这就是待改名的对象）。

4. 把发行版改名为所需名称（注册表法）

WSL 发行版的「名字」记录在注册表里，改名字就是改注册表里的 DistributionName 值。

第 1 步：先关闭 WSL（推荐，避免占用）

第 2 步：打开注册表编辑器

点开 Lxss 下面的每一串大括号 {...} GUID 文件夹，逐个查看里面的 DistributionName 值，找到值等于 Ubuntu 的那一项。

第 4 步：改名

  1. 双击该 GUID 下的 DistributionName；
  2. 把「数值数据」改成你的所需名称，例如：Ubuntu-OpenClaw；
  3. 点击确定保存，关闭注册表编辑器。

改完后重新打开一个 PowerShell，执行 wsl -l -v 验证——应显示新名字。

说明：改名只改显示名和命令行识别名，不会影响已装的软件、用户和文件系统（都存于同一个 ext4.vhdx 虚拟磁盘里），可放心改。

  2. 按 Ctrl + , 进入设置；

6. 网络环境配置（代理 / 直连地址）

WSL 需要与 Windows 共享网络、自动继承代理，并放行不走代理的本地/内网地址。分 Windows 侧 和 Linux 侧 两步。

6.1 配置 .wslconfig（Windows 侧）

在用户主目录 C:\Users\<你的用户名>\ 下新建（或编辑已存在的）文件 **.wslconfig**，写入：

各配置项作用：

配置项 作用
networkingMode=mirrored 镜像网络：WSL 与 Windows 共享网卡/IP，互通更顺畅
autoProxy=true 自动注入 Windows 代理设置，子系统自动走代理
dnsTunneling=true DNS 走隧道转发，避免 DNS 污染
firewall=true 沿用 Windows 防火墙规则
hostAddressLoopback=true 允许 WSL 访问 Windows 宿主的回环地址

改完执行 wsl --shutdown，再重新进入子系统使配置生效。

常见问题与排错

问题现象 原因与解决
注册表里找不到 DistributionName = Ubuntu 实际注册名可能不同（如 Ubuntu-22.04）。执行 wsl -l -v 看真实名字，再去注册表找对应项
改名后 wsl -d <新名> 报「不存在该发行版」 注册表没保存成功或未生效。重开注册表确认值，执行 wsl --shutdown 后再试
双击 ubuntu.exe 闪退/报错 大概率 WSL 功能未启用或改完没重启电脑；或安装包架构（32/64 位）与系统不匹配
解压报「目标目录已存在」 目标目录已有内容，先删除或更换目录名
改完名后原「Ubuntu」快捷方式/命令失效 正常现象，旧名已移除，统一改用 wsl -d <新名>
--unregister 后 wsl -l -v 仍显示 注册表残留，按线索二第 3 步手动删除对应 GUID 项

小结

  • 安装配置：启用 WSL → 解压 .appx → 双击 ubuntu.exe 建用户 → 改注册表 DistributionName 为所需名称 → 同步终端 JSON 显示名 → 配置 .wslconfig + ~/.bashrc 网络 → 用 wsl -d <新名> 管理。
  • 完全卸载：wsl --shutdown → wsl --unregister <新名> → 删残留目录/注册表/终端配置 → 可选 wsl --uninstall 关闭功能。
  • 改名不影响已有数据且可逆；卸载不可逆，卸载前务必确认是否需备份。
