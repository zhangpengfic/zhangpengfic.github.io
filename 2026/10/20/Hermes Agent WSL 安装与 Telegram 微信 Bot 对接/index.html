Hermes Agent WSL 安装与 Telegram / 微信 Bot 对接

文档简介

本文手把手带你在 WSL2 (Ubuntu) 环境下从零部署 Hermes Agent，并完成两大主流 IM 的 Bot 对接：

  • Telegram：通过 @BotFather 创建 Bot，拿到 Token 后 5 分钟上线，支持群聊、语音、文件。
  • 微信：通过腾讯 iLink Bot API 扫码登录个人微信，长轮询收消息，无需公网 IP、无需 webhook。

适用环境：Windows 11 + WSL2 Ubuntu 22.04/24.04。全程命令可直接复制运行。

一、WSL 环境准备

假设你已经装好 WSL Ubuntu（没装的话参考《WSL 安装 Ubuntu 并改名为所需名称》）。

确保系统有 curl（用来下载安装脚本），没有就装一下：

不用手动装 Python / pip / Node.js——Hermes 安装脚本会自己下载并准备好 Python 3.14、Node.js、所有依赖包，全部放在 ~/.hermes/ 目录下，跟系统环境完全隔离，不会跟你系统里的 Python / conda 环境冲突。

三、Gateway 的三种运行方式与 Web 管理界面

3.1 前台运行（调试用）

  • 特点：日志直接打印在终端里，Ctrl+C 就停
  • 使用场景：刚配置完、排查问题、看实时日志。平时不这么跑——关了终端 Bot 就下线了。

3.2 后台运行（日常用）

  • 特点：进程挂到后台，关终端也不影响
  • 使用场景：日常使用，配好 Bot 之后就这么跑

3.3 systemd 开机自启（长期常驻推荐）

想让 WSL 一开起来 Bot 就自动跑，不用每次手动启动，就用 systemd：

装好之后：

  • 特点：WSL 启动自动拉起，崩了自动重启
  • 使用场景：你想让这个 AI 助手 7×24 小时在线，随时手机发消息就能用

前提：WSL 里要先开 systemd（参考你那篇 WSL 安装文章里的 wsl.conf 配置）。

启动后终端会输出一个本地访问地址，类似：

用 Windows 上的浏览器打开这个地址，就是完整的图形界面——可视化聊天窗口、配置面板、会话历史、Bot 管理都在里面。

它跟 Gateway 的关系：

Gateway hermes desktop
本质 后台服务进程 本地 Web 管理界面
跑什么 接 Telegram / 微信，收消息回消息 可视化聊天、改配置、看日志、管理会话
需要一直开着吗 要，Bot 在线全靠它 不用，用完关掉就行，不影响 Gateway 跑
适合干嘛 当 Bot 用，远程手机指挥 本地调试、可视化配置、看历史会话

简单说：

  • Gateway 是发动机，负责真正接 Telegram / 微信、跑 AI 推理，必须一直开着；
  • hermes desktop 是驾驶舱，给你个浏览器里的图形界面方便操作，用完关掉不影响 Bot 运行。

什么时候用 desktop？

  1. 刚装好想可视化配置 Bot、选模型、看日志
  2. 想看历史会话、管理多个 Agent 配置
  3. 不想在终端里敲命令，喜欢点鼠标

什么时候不用？

  • 你就想接个 Telegram / 微信 Bot，手机上发消息用 → 命令行 hermes gateway start 跑着就行，desktop 想开再开，不想开完全不影响。

5.2 扫码登录

运行配置向导：

在提示里选 Weixin（微信）。

接下来向导会做这几件事：

  1. 向 iLink 服务器请求一个登录二维码；
  2. 在终端里直接打印二维码（ASCII 字符画）；
  3. 拿出手机微信，扫这个二维码；
  4. 手机上点确认登录；
  5. 终端显示「微信连接成功，account_id=xxx」。

如果终端二维码渲染不出来，向导会同时打印一个二维码 URL，用手机浏览器打开那个链接也能看到二维码。

登录成功后，账号凭据（account_id、token）会自动保存到 ~/.hermes/weixin/accounts/ 目录下，不用手动复制粘贴。

5.5 微信对接的几个重要限制（必看）

官方文档明确说了，iLink Bot 身份有几个硬限制，别踩坑：

限制 说明
群聊基本没用 iLink Bot 身份通常收不到普通微信群的消息，群聊功能形同虚设。只能用私信（DM）。
不是你的个人微信号 登录后是一个独立的 Bot 身份（类似 a5ace6fd@im.bot），不是你平时用的微信号，好友看不到你的朋友圈。
每个 Token 只能跑一个实例 别同时开两个 gateway 连同一个微信账号，会互相踢。
会话过期要重扫 报错 errcode=-14 就是登录态过期了，重新跑一次 hermes gateway setup 扫码就行。

一句话总结微信对接：当你的私人微信助手用没问题，想拉群里当群管就别想了，iLink 侧不推群消息。

5.6 微信支持的功能

  • ✅ 文字消息（支持 Markdown 渲染，标题/表格/代码块都能显示）
  • ✅ 图片 / 视频 / 文件 / 语音收发（自动 AES-128-ECB 加解密）
  • ✅ 「正在输入…」状态提示
  • ✅ 长轮询收消息，不需要公网 IP、不需要 webhook
  • ❌ 普通微信群消息（iLink 不推送）

命令 作用
hermes gateway setup 交互式配置平台（Telegram/微信等）
hermes gateway 前台启动 Gateway（看日志用）

九、总结

Hermes Agent 在 WSL 下的部署其实很简单，核心就三步：

  1. 跑一键脚本装本体；
  2. Gateway 后台跑起来；
  3. 接 Telegram / 微信 Bot。

最容易踩的坑就是「依赖装错 Python 环境」——记住一句话：Hermes 只认自己 venv 里的包，别往系统 Python 里瞎装。

Telegram 适合自己远程折腾、群聊协作；微信适合日常随手发消息问问题。两个一起开，手机上随时随地指挥你的 AI Agent 干活。
